Sprite Atlas Cleaner — User Guide

1. Open an atlas

Drop a PNG/WebP/JPG onto the canvas, or click Open PNG.

  • Transparent PNG gives the cleanest detection.
  • Solid/near-solid backgrounds can be handled with flood-fill.

2. Auto Detect

Click Auto Detect to find sprite islands.

  • Alpha threshold: minimum alpha counted as foreground.
  • Min area: ignores tiny noise components.
  • Group distance: groups nearby detached pieces.
  • BG tolerance: background color tolerance for flood-fill mode.

Workspace layout

  • Left: global tools and settings.
  • Center: main canvas workspace.
  • Right: sprite list and selected sprite properties.
  • Use ☰L / R☰ in the toolbar to collapse sidebars and maximize canvas space.

3. Select sprites

  • V or Select: return to select mode.
  • Click a sprite on the canvas to select it.
  • Shift + click: multi-select.
  • You can also select from the detected object list on the right.

4. Merge / Split

  • Merge Selected: combine multiple detected boxes into one sprite.
  • M: merge shortcut.
  • Split Islands: split one sprite into separate connected components.
  • Delete: remove unwanted detected objects.

5. Mask editing

  • E / Erase Brush: remove pixels from the selected mask.
  • R / Restore Brush: restore pixels from the original source.
  • A circular cursor shows the current brush footprint.
  • Esc or V: return to Select.

6. Brush size

  • Change Brush size numerically in the panel.
  • Right mouse drag on canvas: drag right to increase, left to decrease.
  • The brush preview updates in real time.

7. Viewport controls

  • Mouse wheel: zoom in/out.
  • Alt + left-drag: pan.
  • Middle mouse drag: pan.

8. Numeric settings

  • Click a number field to type an exact value.
  • Use the browser stepper arrows.
  • Left-drag horizontally on a number field to scrub its value.
  • Shift + drag: fine adjustment.
  • Ctrl/Cmd + drag: faster adjustment.

9. Packing & Preview

  • Atlas size: output texture dimensions.
  • Padding: empty space between sprites.
  • Extrude: duplicates edge pixels to reduce texture bleeding.
  • Preview Packed Atlas: inspect the exact MaxRects result before downloading.
  • Inside Preview you can change Atlas size, Padding, Extrude and Export mode.
  • Use Repack manually or enable Auto Repack to rebuild immediately when settings change.
  • Preview supports zoom, pan, frame boxes, names, hover inspection and direct export.

10. Export

  • ZIP atlas mode: exports atlas.png, atlas.json, segmentation.json.
  • PNG only: exports just the packed atlas.png.
  • All individual sprite PNGs: exports a ZIP containing one native-resolution trimmed PNG per detected sprite.
  • Selected PNG: exports the currently selected sprite as a standalone trimmed PNG.
  • Repeated exports do not require reloading the page.
Recommended workflow:

Open image → Auto Detect → Select → Merge/Split → Erase/Restore mask → Rename in Selected Sprite → Open Packing → Preview Packed Atlas → Export
